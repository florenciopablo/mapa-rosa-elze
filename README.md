# Mapa Rosa Elze

Mapa de endereços (CNEFE / Censo 2022) dos bairros Rosa Elze, Eduardo Gomes, Rosa Maria, Tijuquinha e Madre Paulina, em São Cristóvão/SE, com marcação de ruas finalizadas sincronizada em tempo real entre o site e o app Android.

- Site: https://florenciopablo.github.io/mapa-rosa-elze/
- App Android: [app/MapaRosaElze.apk](app/MapaRosaElze.apk)

Fonte dos dados: IBGE — Cadastro Nacional de Endereços para Fins Estatísticos (CNEFE) e Base de Faces de Logradouros, Censo Demográfico 2022.
